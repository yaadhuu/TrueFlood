Each node simulates 5 sensors: HC-SR04 for water level, potentiometers for rainfall and soil saturation, BMP180 for barometric pressure trend, DHT22 for humidity — plus LCD, tri-color LEDs and buzzer for local alerting. Every part is labeled on-canvas. Run up to 4 tabs simultaneously, each publishing under its own NODE_ID. Load firmware/diagram_node<N>.json and firmware/sketch.ino per node — see firmware/NODES_SETUP.md for the full sensor map.
